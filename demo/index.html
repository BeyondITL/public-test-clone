Prepare your source here, draft with Claude in your own account, then check the draft against the source, edit it and export. This page does the checking and the artwork. It does not generate text.

How to use this page
  1. Load an example to see a finished set, or paste a transcript you have the rights to. SRT and VTT files keep their timecodes. Plain text has none.
  2. Press Prepare source. Each passage gets an ID such as C001.
  3. Press Copy request for Claude and paste it into Claude with one of the kit's skills installed. Claude returns JSON.
  4. Paste that JSON under Draft and press Validate. The page checks that every cue ID exists and that reel times match the cited cues.
  5. Read the draft against the source list. Beside the preview, switch between Slides, Reels and Posts to edit the text.
  6. Tick the approval box, then download PNG slides, a PDF, the copy as Markdown, or the JSON. Each reel script and post also gets its own Copy button.

What it cannot do: it does not watch video, clip video, post for you, or judge whether a paraphrase is true. That review is yours.
